# lispy

This library ports some Common Lisp functions/macros to rust.
The following functionality has been ported:

- map
- map2
- map_into
- map_into2
- mapcar
- mapcar2
- maplist
- mapl
- mapc
- mapcan
- mapcon
- some
- every
- notany
- notevery
- reduce
- ntimes
- dotimes
- cond
- when
- unless
- incf
- decf
- prog1
- prog2
